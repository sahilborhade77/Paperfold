## ✨ About

Paperfold is a modern web application that lets users create personalized digital memory cards.

Each card can include:

- 📸 Photo
- ✍️ Handwritten-style letter
- 🎵 Music
- 🎨 Beautiful themes
- 🔗 Shareable link

Perfect for birthdays, anniversaries, thank-you notes, long-distance relationships, and special memories.

---

## 🚀 Features

- 🎨 Beautiful templates
- 📷 Upload or capture photos
- ✍️ Rich letter editor
- 🎵 Upload custom music
- 💾 Draft saving
- 📂 Archive management
- 📱 Responsive design
- ☁️ Supabase cloud storage
- 🔗 Share cards with a unique URL
